# Hangmi — character bible

KKorea Hangul mascot: a friendly tabby cat who helps learners with Hangul.

## Identity

- **Name:** Hangmi
- **Species:** Warm grey-gold tabby cat (mèo mướp)
- **Signature:** Forehead tabby marking shaped like Hangul **ㅎ** (must stay readable at ~64px)
- **Eyes:** Large, warm amber-brown, friendly
- **Proportions:** Big head (~45–50% of height) for icon readability
- **Accessory (optional):** Small scarf or badge with **가** — never crowd the silhouette
- **Tone:** Study companion, warm, not overly childish

## Art style

- Flat 2D, clean thick outlines, soft pastel shading
- Match Liquid Glass app palette vibes (lavender / soft blue / pink accents)
- Transparent or simple soft circular backdrop for in-app poses
- **Not** 3D glossy / photoreal
