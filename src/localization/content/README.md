Lesson translations are bundled locally; the running app never calls a translation service.

`fromVietnamese` translates grammar titles, tags, formulas, explanations, usage, example meanings/notes, and reading sentence meanings. `fromEnglish` translates existing English vocabulary meanings, privacy text, and the language-neutral app description. Vietnamese continues to use the original source data; English vocabulary continues to use its original English meanings.

The initial additional translations were generated with Google Translate using `node scripts/build-learning-translations.mjs`. Korean text is protected and restored verbatim. These are machine translations; language specialists should review terminology and wording before publication. Edit catalog values directly to refine translations: the generator preserves existing entries. Regenerate missing entries when source content changes, then run `npm test -- --runInBand` and `npm run typecheck`. Coverage tests check every built-in lesson field and verify that Korean examples/formulas survive unchanged.

Ambiguous grammatical terms have reviewed English equivalents in `scripts/learning-translation-glossary.json`, with selected lesson corrections in `scripts/grammar-english-edits.json`; other language catalogs translate these equivalents instead of isolated Vietnamese terms. Use `--refresh-glossary` to update those entries after editing them.

`src/data/sentenceRomanization.json` bundles whole-sentence romanization guides generated by the same script. Reading practice uses these for the Romanization system and for the default guide outside Vietnamese. The original Vietnamese guides remain available when Vietnamese and the default system are selected; explicit IPA uses the existing syllable phonetics.
